# AI PRDs

One AI PRD per feature, each following the 13-part one-page AI PRD template (problem and user, why AI, objective and metrics, approach options, data, eval plan, failure modes, human in the loop, responsible AI, cost, latency, launch plan, open questions).

`00_SHARED_ASSUMPTIONS.md` holds what is common: model prices (checked), token sizes (assumed), blended monthly cost, latency model, human capacity, responsible AI commitments and the launch template. **Read it first.**

|---|---|---|
| F01 Shortlist | `F01_shortlist_AI_PRD.md` | Reads needs; writes reasons |
| F02 Second opinion + pitch check | `F02_second_opinion_and_pitch_check_AI_PRD.md` | Reads claims; verdicts only from approved ledger |
| F03 Used laptop check | `F03_used_laptop_check_AI_PRD.md` | Reads the listing; rules flag |
| F04 Buy for others or a team | `F04_buy_for_others_and_teams_AI_PRD.md` | Reads recipient and messy tables |
| F05 Owner voice | `F05_owner_voice_AI_PRD.md` | Reads questions; labels reviews offline |
| F06 Add my experience | `F06_add_my_experience_AI_PRD.md` | Optional triage; a human approves |
| F07 Market pulse | `F07_market_pulse_AI_PRD.md` | None, by design |

| F09 Sell plan | `F09_sell_plan_AI_PRD.md` | Reads condition; rules value |
