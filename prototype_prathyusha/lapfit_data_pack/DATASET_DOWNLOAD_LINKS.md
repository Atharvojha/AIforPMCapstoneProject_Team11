# Direct dataset download references

These URLs are provided so the source files can be fetched locally. The ZIP's `download_datasets.py` automates the supported direct-download routes.

| Dataset | Landing page | Direct file / API download |
|---|---|---|
| Flipkart Review Dataset | https://zenodo.org/records/17612521 | https://zenodo.org/records/17612521/files/data.zip?download=1 |
| Amazon India extraction dataset v2 | https://data.mendeley.com/datasets/2pv6d8fz7y/2 | https://api.data.mendeley.com/datasets/2pv6d8fz7y/zip/file_downloaded?version=2 |
| PCBox products CSV | https://zenodo.org/records/14060666 | https://zenodo.org/records/14060666/files/products_pcbox.csv?download=1 |
| Amazon Reviews'23 Electronics reviews | https://amazon-reviews-2023.github.io/ | https://mcauleylab.ucsd.edu/public_datasets/data/amazon_2023/raw/review_categories/Electronics.jsonl.gz |
| Amazon Reviews'23 Electronics product metadata | https://amazon-reviews-2023.github.io/ | https://mcauleylab.ucsd.edu/public_datasets/data/amazon_2023/raw/meta_categories/meta_Electronics.jsonl.gz |

The Amazon Reviews'23 Electronics category contains a large number of records and includes more than laptops. It is an optional research download, not part of the small prototype setup.
