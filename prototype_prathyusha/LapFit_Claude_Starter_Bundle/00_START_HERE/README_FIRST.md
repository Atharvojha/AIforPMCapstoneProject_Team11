# LapFit Claude Starter Bundle

## Start here

1. Extract this bundle into a new project workspace.
2. Open the folder in Claude Code (recommended) or upload all three files into a Claude conversation/project with code execution enabled.
3. Read and follow `LapFit_Claude_Master_Prompt.md` first.
4. Extract `LapFit_Data_Pack.zip` when the prompt instructs you to audit the files.
5. Use `LapFit_Detailed_Product_and_Technical_Plan.md` as the product/technical reference, not as a substitute for collaborative decisions.

## Files

- `00_START_HERE/LapFit_Claude_Master_Prompt.md` — the main collaboration, ideation, design, AI architecture and build instructions.
- `01_PRODUCT_PLAN/LapFit_Detailed_Product_and_Technical_Plan.md` — the existing detailed product and technical plan.
- `02_DATA/LapFit_Data_Pack.zip` — the data starter pack with source PDF, extracted text, golden-example summaries, data templates, catalog, downloader and licence notes.

## Important data limitation

The data pack is not a complete raw-data dump. It does not include the raw 97-review CSV or the 3,300-review laptop extract as standalone files, and external dataset binaries are not pre-downloaded. Claude must verify actual files and must not fabricate missing records.
