What a live-researched report can and cannot include

Specs and independent test facts, each with a link. Owner reviews only if a permitted source provides them, so the Owner lane often says “no owner evidence available” and ratings stay conservative.

Anything typed gets a response
  • Typo or alias: “Did you mean …?”
  • Not a laptop: “LapFit answers laptop questions. Try a model or a claim.”
  • Claim without a laptop: asks which laptop.
  • Offline or no search key: says live research is unavailable and shows the catalogue only.
Design notes
  • This implements the “whole app is real” requirement: nothing is canned. Catalogue laptops are fast and deep; any other laptop is researched on demand, slower and thinner, and labelled as such.
  • Open decisions for you: which search provider and key to use, and which domains are allowed for fetching.
  • Live research always shows when it was run, which sources it fetched and which it only linked.

Coverage = (20 + 10) / 100 = 30%. Below the 60% threshold, so no number is shown.

The rule in words

Score = weighted average of the categories that have enough evidence. Coverage = share of the total weight that has evidence. A number is shown only at 60% coverage or more. A failed hard requirement overrides the average. Missing data is never counted as zero or as a pass. The model never calculates any of this.
