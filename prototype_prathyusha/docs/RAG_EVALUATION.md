Principle: evaluate **before** building features claim to be reliable; freeze golden sets before scoring; report actual measured numbers; the earlier team's targets are goals, not achievements.

## 2. Metrics (log per run: model, prompt version, embed model, data_version, git-less commit hash of files)
Fit: dealbreaker recall (target ≥85% — from PRD, not yet achieved by earlier arm: best 56%), false-dealbreaker item rate (≤10%), overconfidence (≤10%), insufficient-evidence accuracy, applicability precision/recall, contradiction detection P/R.
Integrity: **quote exact-match 100%**, citation validity 100%, numeric/unit validity 100%, injection-follow rate 0%, SSRF block rate 100%.
Retrieval: recall@5/10, MRR, exact-variant filter accuracy, duplicate inflation (should be 0), low-similarity rejection rate.
Claim: type-routing accuracy, verdict accuracy vs adjudication, condition-comparability accuracy, counter-evidence-executed rate (100%), "insufficient" correctness.
Live: identity-resolution accuracy, extraction field accuracy vs human, link-only compliance 100%, cache hit rate, p50/p95 latency, credits/report.
Ops: p50/p95 per stage, model failures, JSON-valid rate, tokens/s.
Judge (optional): Ragas faithfulness/answer-relevancy with a **calibrated** judge (kappa ≥0.6 vs humans on ≥40 items); never the only evidence.

## 3. Baselines and ablations
Rules-only baseline (ported `baseline_rules.py`: recall 0.375, false-DB item rate 0.65 vs AI-drafted labels). Ablations: lexical-only vs vector-only vs hybrid(RRF) vs hybrid+rerank; with/without applicability stage; with/without dedup; prompt v1/v2/v3; embedding model A/B/C.

## 4. Model-selection protocol (no training)
Pick the smallest local model that passes the extraction/claim gates. Smoke benchmark (needs no gold labels): JSON-valid rate, quote-exactness, injection-follow rate, tokens/s, peak memory, over 40 real review snippets (short, Hinglish, shorthand, adversarial). Then accuracy on G-EXT. Candidates: llama3.1:8b (installed), qwen3:8b, qwen2.5:7b, llama3.2:3b (small fallback), qwen3.5:9b (if memory allows). **Blocked by network (CH-018): only llama3.1:8b available locally now.**
Embeddings: recall@k on G-RET for multilingual-e5-base vs bge-m3 vs MiniLM-L12-multilingual; reranker only if recall@5 improves ≥3 points for ≤300 ms/query.

## 5. Process rules
Freeze (hash) each golden set before first scored run; no edits after seeing results; log every labelling change as a new version; two runs per prompt to measure noise (carry over the earlier team's noise-band method); regressions block merges (pytest gate on deterministic assertions; metric gates on the nightly eval run).
